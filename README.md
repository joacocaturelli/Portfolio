# Joaquín Caturelli — Portfolio

Portfolio personal desarrollado con **React + Vite** para presentar proyectos, stack técnico y datos de contacto.

## Stack

- React
- JavaScript
- Vite
- HTML5
- CSS3
- Google Fonts

## Proyecto destacado

### E-commerce Full Stack

Aplicación e-commerce desarrollada de principio a fin con:

- React, Redux Toolkit, React Router y Axios
- Node.js + Express
- PostgreSQL + Prisma
- Autenticación JWT mediante cookies HTTP-only
- Stripe para pagos de prueba
- Cloudinary para imágenes
- Testing con Jest
- Swagger / OpenAPI y Postman

**Demo:** https://mitienditaonline.netlify.app

**Frontend:** https://github.com/joacocaturelli/ecommerce-frontend

**Backend:** https://github.com/joacocaturelli/ecommerce-api

**API docs:** https://backend-e-commerce-keoz.onrender.com/api/docs

## Desarrollo local

Instala las dependencias y arranca el servidor de desarrollo:

```bash
npm install
npm run dev
```

Para generar una build de producción:

```bash
npm run build
npm run preview
```
